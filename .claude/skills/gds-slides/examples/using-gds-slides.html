Set it up once

  • Install it from govuk-once/gds-claude-plugins
  • Or work in a repo that already includes it
  • Ask Claude to run the gds-slides setup check
5

Install with /plugin marketplace add govuk-once/gds-claude-plugins, then /plugin install gds-slides@gds-claude-plugins. The setup check reports anything missing and how to fix it. Python 3 is enough for HTML decks; PowerPoint needs python-pptx, and previews need DeckCraft.

Five steps from brief to deck

Claude agrees the headings with you before it writes the outline, so changing the story costs nothing.

7

Brief: who the deck is for and the one thing they should take away. Headings: for you to approve. Outline: a Markdown file you can read and edit, a heading per slide, with detail in the speaker notes. Build: both formats at once. Look: Claude checks every slide and fixes the outline until they all pass.

To change a deck, change the outline

Ask Claude to edit the outline, or edit it yourself, then rebuild. Polish in PowerPoint once the story is settled, because a rebuild replaces those edits.
